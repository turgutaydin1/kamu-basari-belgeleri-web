KAMU KURUMLARI BAŞARI BELGELERİ - GOOGLE SITES + APPS SCRIPT KURULUMU

BU SÜRÜMDE:
- Railway yok.
- Google Cloud VM yok.
- Docker yok.
- Yeni hosting hesabı yok.
- Mevcut Google ve GitHub hesabın yeterli.

KULLANILANLAR:
Google Sites + Google Apps Script + Google Sheets + Google Drive + GitHub

KISA KURULUM:

1) https://script.google.com adresine mevcut Google hesabınla gir.
2) Yeni proje oluştur. Ad: Kamu Başarı Belgeleri Web
3) GitHub deposunda apps-script/Code.gs dosyasını aç.
4) Apps Script'teki Code.gs içeriğini tamamen sil ve GitHub'daki Code.gs içeriğini yapıştır.
5) Apps Script sol taraf + > HTML seç. Dosya adı: Index
6) GitHub'daki apps-script/Index.html içeriğini buraya yapıştır.
7) Apps Script > Proje Ayarları > appsscript.json manifestini göster seçeneğini aç.
8) appsscript.json dosyasını GitHub'daki apps-script/appsscript.json içeriğiyle değiştir.

İLK KURULUM:
9) Code.gs dosyasının EN ALTINA geçici olarak şunu ekle:

function ilkKurulum() {
  setupSystem('KENDI_EPOSTA_ADRESIN');
}

10) KENDI_EPOSTA_ADRESIN yerine kendi Gmail/Google e-posta adresini yaz.
11) Üst fonksiyon listesinden ilkKurulum seç ve Çalıştır de.
12) Google izin isterse Sheets ve Drive erişimine izin ver.
13) Google Drive'da otomatik olarak şu iki şey oluşur:
    - Kamu Başarı Belgeleri - Sistem Veritabanı
    - Kamu Başarı Belgeleri - Kullanıcı Verileri

WEB UYGULAMASINI YAYINLA:
14) Apps Script sağ üst > Dağıt > Yeni dağıtım.
15) Tür: Web uygulaması.
16) Şu kullanıcı olarak çalıştır: Ben.
17) Erişimi olanlar: Herkes.
18) Dağıt de.
19) Sana verilen https://script.google.com/macros/s/.../exec adresini kopyala.

YÖNETİCİ HESABI:
20) /exec adresini aç.
21) Kendi e-posta adresinle Üye Ol kısmından kayıt aç ve parolanı belirle.
22) Apps Script editörüne dön, ilkKurulum fonksiyonunu bir kez daha Çalıştır.
23) Hesabın ADMIN + FULL olur.

DENEME TESTİ:
24) Gizli sekme aç.
25) /exec adresine gir.
26) Farklı e-posta ile Üye Ol.
27) Giriş yap.
28) Varsayılan sınır 7 gün / 10 kayıttır.
29) Yeni belge kaydı oluştur.
30) Kayıtlar bölümünde kaydın durduğunu kontrol et.
31) Çıkış yap ve tekrar giriş yap; kayıt kalıcı olmalıdır.

ÜYE YÖNETİMİ:
32) Kendi yönetici hesabınla giriş yap.
33) Üye Yönetimi sekmesini aç.
34) Kullanıcıyı TRIAL, FULL veya BLOCKED yapabilirsin.
35) Deneme gününü ve kayıt limitini değiştirebilirsin.

GOOGLE SITES'E GÖMME:
36) https://sites.google.com adresinde siteni aç.
37) Sağ panel > Ekle > Yerleştir.
38) URL olarak Apps Script /exec adresini yapıştır.
39) Ekle de.
40) Uygulama alanını genişlet ve siteyi yayınla.
