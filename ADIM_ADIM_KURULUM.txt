KAMU KURUMLARI BAŞARI BELGELERİ - GOOGLE CLOUD + GOOGLE SITES KURULUMU

ÖNEMLİ:
- Railway kullanılmıyor.
- Yeni bir üçüncü taraf hosting hesabı açılmıyor.
- Mevcut Google hesabınızla Google Cloud kullanılacak.
- GitHub'daki dosyalar kalacak; GitHub yalnız kaynak kod deposu olacak.
- Kullanıcı verileri GitHub'a yazılmayacak.
- Kullanıcı verileri Google Cloud VM'nin kalıcı diskinde /opt/basari-data altında tutulacak.
- Tam ayrıntılı anlatım için GOOGLE_CLOUD_KURULUM.md dosyasını açın.

KISA SIRA:
1) Google Cloud Console'a mevcut Google hesabınla gir.
2) Yeni proje oluştur: kamu-basari-belgeleri.
3) VPC Network > IP addresses bölümünden Regional Static IPv4 ayır.
4) Compute Engine'de Ubuntu 24.04 veya Debian 12 VM oluştur.
5) External IPv4 olarak ayırdığın sabit IP'yi seç.
6) Allow HTTP ve Allow HTTPS seçeneklerini işaretle.
7) VM'de SSH aç.
8) Şunları çalıştır:

sudo apt update
sudo apt install -y docker.io docker-compose-v2 git
sudo systemctl enable --now docker
cd /opt
sudo git clone https://github.com/turgutaydin1/kamu-basari-belgeleri-web.git basari-web
sudo chown -R $USER:$USER /opt/basari-web
cd /opt/basari-web
cp .env.example .env
nano .env

9) .env içinde şu alanları doldur:
WEB_ADMIN_EMAIL=kendi e-posta adresin
WEB_ADMIN_PASSWORD=guclu bir parola
WEB_TRIAL_DAYS=7
WEB_TRIAL_RECORD_LIMIT=10
WEB_SESSION_DAYS=7
APP_DOMAIN=SABIT_IP_ADRESIN.sslip.io

10) Ardından:
sudo mkdir -p /opt/basari-data
sudo chown -R $USER:$USER /opt/basari-data
docker compose up -d --build

11) Tarayıcıda:
https://SABIT_IP_ADRESIN.sslip.io
adresini aç.

12) Yönetici hesabınla giriş yap.
13) Gizli sekmede yeni deneme üyesi oluştur ve 7 gün / 10 kayıt sınırını dene.
14) Google Sites > Ekle > Yerleştir (Embed) bölümüne aynı https adresini koy.
15) Siteyi yayınla.

GÜNCELLEME:
GitHub'a yeni kod geldiğinde VM'de:
cd /opt/basari-web
git pull
docker compose up -d --build

KULLANICI VERİLERİ KOD GÜNCELLEMESİNDE SİLİNMEZ; /opt/basari-data ALTINDA KALIR.
