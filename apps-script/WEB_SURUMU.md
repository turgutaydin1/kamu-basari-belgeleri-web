# Web Sürümü

Kaynak: `BasariProgrami.zip` içindeki güncel çalışan `app.py`, `system_config.json` ve dört gerçek belge şablonu.

Durum akışı: `TASLAK -> OLUR_LISTESINDE -> PDF HAZIRLA -> TESLIM_EDILDI`.

Bu dosyanın bulunduğu `apps-script/` klasörü modüler geliştirme kaynağıdır. Google Apps Script'e aktarılacak sade paket `apps-script-deploy/` klasöründe otomatik üretilir.
